# Kavish Singh

I design, build and operate production systems with AI coding agents. I write the specs, direct the agents, review what they draft, test it, ship it and keep it running. The work is developer tools, home-server infrastructure and the systems a retail store runs on.

Founder of Nexus Vantage Group, a one-person software studio in Sacramento, California.

## Selected systems

- **[Cokpit](https://kavishsingh.com/work/cokpit/)**, a workbench for coding-agent sessions: terminals that outlive the window, a live diff of what each agent changed, a control plane one agent can drive, and a hub that keeps sessions alive on a home server. Rust, Tauri, React.
- **[Sayso](https://kavishsingh.com/work/sayso/)**, push-to-talk dictation for Windows that learns the speaker's vocabulary and types into whatever program is in front. Rust, Tauri. Open source under Apache-2.0: [github.com/Straughz/sayso](https://github.com/Straughz/sayso).
- **[Routr](https://kavishsingh.com/work/routr/)**, a dispatcher that picks the model for each task, enforces the pick and keeps two subscriptions inside their limits. Python.
- **[Hub and server infrastructure](https://kavishsingh.com/work/hub-infrastructure/)**, a Proxmox host and Ubuntu hub VM for persistent sessions, services and private source hosting, on a Tailscale network with no open ports.
- **[Retail store kiosk](https://kavishsingh.com/work/store-kiosk/)**, a self-service print and ship kiosk with signed auto-updates, usage billing and walk-away sessions. Python, Rust, Square.
- **[Customer upload portal and staff dashboard](https://kavishsingh.com/work/store-website/)**, a store website with a file-upload front and a staff dashboard behind two-factor sign-in. Python, Flask.
